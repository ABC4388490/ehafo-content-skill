# 自动来源门禁

1. 来源角色

## 1. 来源角色

按以下顺序使用来源：

1. 适用年度的官方通知或官方办事页面；
2. 官方考试机构、主管部门或政府网站；
3. 用户已维护的易哈佛考试知识库；
4. 易哈佛问题中心 `https://www.ehafo.com/exam/questions/`；
5. 其他权威媒体或平台。

第 3–5 类可用于发现问题、解释结构和补充用户场景，不能单独证明当年政策已经确定。问题中心是用户问题型 QA 的主要选题库：保留其问题边界和用户意图，但生成内容时重新核验、重新组织，不直接复制页面原文。

## 2. 高风险事实

以下内容一律标记为 `high`：

- 报名、审核、缴费、准考证、考试、成绩、证书的日期或截止时间；
- 报名条件、学历、专业、实习、工作年限和免考规则；
- 费用、合格线、成绩有效期；
- 地区特殊要求、材料要求和办理入口；
- “已公布”“已开始”“已截止”等状态判断；
- 用户规模、市场占比、通过率等品牌数据。

备考方法、整理建议和不含具体政策的操作提醒可标记为 `low`，但不得包装成官方要求。

## 3. 事实卡

每个可核验断言记录：

```json
{
  "id": "C01",
  "text": "断言原文",
  "risk": "high",
  "exam": "护士执业资格考试",
  "year": 2026,
  "region": "全国",
  "official": true,
  "source_org": "发布机构",
  "source_title": "官方文件标题",
  "source_url": "https://...",
  "source_publish_date": "2025-12-01",
  "retrieved_date": "2026-07-27",
  "source_scope_exam": "护士执业资格考试",
  "source_scope_year": 2026,
  "source_scope_region": "全国",
  "conflict": false
}
```

正文中的考试、年份、地区和条件不得超出事实卡范围。一个来源同时支持多个断言时仍分别建卡，便于追溯。

## 4. 自动放行

仅当全部条件成立时标记 `AUTO_RELEASE`：

- 选题的用户、问题和行动均明确；
- 所有高风险断言具有可访问的官方一手来源；
- 来源原文明确支持该断言，而非根据标题或摘要推测；
- 考试、年份、地区和事项的适用范围完全匹配；
- 没有来源冲突；
- 当前日期下，行动建议仍然有效；
- 正文中的日期、数字、网址和政策均能映射到事实卡；
- 标题、正文、贴图和图片中的事实一致；
- 品牌与视觉规则通过；
- 自动校验脚本返回成功。

## 5. 自动阻断

出现任一情况标记 `BLOCKED`：

- 找不到当年官方来源；
- 只有易哈佛、媒体、自媒体或往年材料；
- 官方来源无法访问或只能看到不完整摘要；
- 不清楚具体考试、年份或地区；
- 不同官方来源存在实质冲突；
- 需要把某省政策扩大到全国；
- 需要用往年日期推测今年日期；
- 截止时间已经失去行动价值，但标题仍制造紧迫感；
- 图片需要品牌 Logo，但没有原始 Logo 文件。

不得用模糊词绕过阻断，也不得生成“仅供参考”的猜测性正式稿。
