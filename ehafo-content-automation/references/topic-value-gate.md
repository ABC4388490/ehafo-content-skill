## 1. 适用范围

用户要求“今天最值得发布”“自动选题”“本周选题”或没有指定具体题目时，必须执行本门禁。

价值判断与形式判断分开：

- 先选出值得做的题；
- 再决定适合考讯、文章、贴图或必要组合；
- 不得因为某题容易做成 6 张图，就提高它的价值排名。

## 2. 候选题建立

自动选题时建立彼此实质不同的真实候选题。数量由当前能找到可靠证据的用户问题决定；只有一个候选时不得声称完成了“最优排名”。候选题应来自：

- 当前官方通知和办事节点；
- 易哈佛医学考试问题中心；
- 用户已有考试知识库；
- 已知的高频错误、报名障碍和备考决策；
- 用户近期留言、搜索词或内容数据（如可访问）。

同一问题的不同标题只算一个候选题。不得用近义标题凑足候选数量。

每个候选题先写清：

- `audience`：具体服务谁；
- `problem`：正在解决什么现实问题；
- `action`：看完后能立即完成什么动作；
- `evidence_status`：关键事实能否由适用的一手来源支持；
- `valid_now`：当前日期下是否仍有行动价值。

## 3. 价值硬门槛

出现任一情况直接淘汰，不参与评分：

- 服务对象只能写成笼统的“所有考生”；
- 只能介绍知识，无法形成判断、操作或复习改进；
- 当前已过期，且没有长期搜索价值；
- 关键事实只有猜测、转载或往年资料；
- 与近期已发布内容实质重复，且没有新政策、新场景或更好解决方案；
- 主要价值只是为易哈佛产品导流；
- 依赖夸大焦虑、绝对承诺或标题误导才能吸引点击。

用户指定题目时也执行本门槛。未通过时返回 `BLOCKED_VALUE`，不生成可发布稿。

## 4. 100 分评分

每项先按 0–5 分评价，再乘权重换算：

| 维度 | 权重 | 评价对象 |
|---|---:|---|
| 即时有用性 | 25 | 看完后是否能解决用户此刻的真实问题 |
| 覆盖人数 | 20 | 在已明确的目标人群中，实际受影响范围有多大 |
| 避免损失 | 20 | 不知道或做错会造成多大且多难补救的损失 |
| 可执行性 | 20 | 内容能否给出可直接照做的完整路径 |
| 当前相关性 | 15 | 该问题与当前考试阶段和行动窗口的距离 |

换算公式：

```text
总分 =
即时有用性÷5×25 +
覆盖人数÷5×20 +
避免损失÷5×20 +
可执行性÷5×20 +
当前相关性÷5×15
```

每项必须有一句基于事实的评分理由。不得用“感觉重要”“应该很多人关注”作为理由。

品牌、产品承接和导流潜力不得进入评分，也不得作为并列时的排序条件。

分数解释：

- 80–100：优先生产；
- 65–79：可生产，但仅在没有更高价值候选时选择；
- 低于 65：不作为自动发布选题。

评分高不代表事实门禁通过。来源核验仍按 `source-gate.md` 单独执行。

## 5. 0–5 分锚点

严格使用下列锚点，不得自行放宽。处于两档之间时取较低分。

### 5.1 即时有用性（25 分）

| 原始分 | 可观察标准 |
|---:|---|
| 0 | 只有背景、宣传或泛知识，看完不能形成任何判断或动作 |
| 1 | 只能增加了解，对当前决定几乎没有帮助 |
| 2 | 能回答一个低影响小问题，但不改变用户下一步 |
| 3 | 能完成一个明确判断或一般操作，但不紧迫且替代信息容易获得 |
| 4 | 能解决当前常见问题，直接推进报名、考试、办证或复习安排 |
| 5 | 能让用户当天完成关键判断或关键操作，错过当下信息会明显影响结果 |

### 5.2 覆盖人数（20 分）

仅在已定义的目标人群内部评价，不得拿“全国医护总人数”替代实际受影响人数。

| 原始分 | 可观察标准 |
|---:|---|
| 0 | 无法说明谁会受影响，或没有任何范围依据 |
| 1 | 极少见个案或非常窄的特殊情形 |
| 2 | 明确的小众子群体，例如特定学历、特殊审核或少数地区情形 |
| 3 | 一个有实际规模的明确群体，但不是当前阶段多数人 |
| 4 | 当前阶段的大多数目标用户都会遇到 |
| 5 | 官方规则适用于几乎全部目标用户，且当前阶段人人都需要处理 |

没有可靠人数数据时，不编造百分比。使用官方适用范围、考试流程覆盖阶段、用户问题数据或近期内容数据作为依据；只有“大家都关心”不得高于 1 分。

### 5.3 避免损失（20 分）

同时考虑损失严重度与能否补救。仅有“可能焦虑”不算实际损失。

| 原始分 | 可观察标准 |
|---:|---|
| 0 | 不知道或做错基本没有实际后果 |
| 1 | 只造成轻微困惑或少量重复操作 |
| 2 | 造成可轻松补救的时间浪费、材料返工或低额成本 |
| 3 | 可能影响一次办理、阶段复习效率或产生明显返工，但仍有常规补救路径 |
| 4 | 可能造成资格误判、缴费/材料错误、较大时间金钱损失，补救困难 |
| 5 | 可能错过不可逆截止、失去当次考试/注册机会，或造成难以挽回的重大后果 |

### 5.4 可执行性（20 分）

评价“这篇内容能提供什么”，不是评价用户本来是否会操作。

| 原始分 | 可观察标准 |
|---:|---|
| 0 | 没有行动建议 |
| 1 | 只有“关注通知、认真备考、及时处理”等空泛建议 |
| 2 | 给出一个方向或单一步骤，但缺少条件、入口或后续动作 |
| 3 | 给出可理解的主要步骤，但仍缺少一项关键要素 |
| 4 | 提供完整步骤、必要条件/材料、官方入口或异常处理中的大部分 |
| 5 | 用户无需另找攻略即可执行：有判断条件、顺序、材料/入口、时间要求和错误处理 |

若官方尚未提供入口、材料或规则，不得因“可以以后补充”给 4–5 分。

### 5.5 当前相关性（15 分）

| 原始分 | 可观察标准 |
|---:|---|
| 0 | 已过期且没有长期搜索或后续行动价值 |
| 1 | 与当前考试阶段明显脱节，只可能偶尔被搜索 |
| 2 | 长期有效，但当前没有对应决策或行动窗口 |
| 3 | 属于当前备考阶段的稳定需求，用户现在处理合理但不紧迫 |
| 4 | 已进入相应流程阶段，或预计近期需要处理，当前发布正合适 |
| 5 | 官方事项刚发布、正在开放、临近截止或结果刚公布，用户现在必须关注或行动 |

不得仅因标题含“2026”给高分。5 分必须有明确官方事件或可核验的当前窗口。

## 6. 评分证据与校准

每项评分理由必须同时写出：

1. 已观察到的事实；
2. 该事实对应哪一档锚点；
3. 依据类型：官方适用范围、官方时间窗口、用户问题数据、历史内容数据或明确流程事实。

不得使用以下表述作为评分依据：“感觉”“应该”“大概”“可能很多”“大家都”“很重要”。没有证据时按 0–1 分处理，不得用常识补高分。

先分别评分，再计算总分。不得先设定目标总分，再倒推各项分数。候选题评分后执行一次横向校准：

- 同类候选的相同事实必须得到相同分值；
- 高一档必须能指出比低一档多满足的具体条件；
- 若两个评分者可能合理相差 2 分以上，说明理由不足，取较低分并补证据；
- `65` 只是自动生产最低线，不得为了越线把任一维度上调。

候选题进入最终排名前，检查总分构成。任何单项为 0 分时，即使总分达到 65，也不得自动选择；这表示选题存在无法解释的价值缺口。

## 7. 时效优先

候选题同时满足以下条件时标记 `time_override=true`：

- 存在新发布、新开启、重大调整、结果公布或临近截止的官方事件；
- 影响目标人群的报名、审核、缴费、准考证、考试、成绩或证书办理；
- 当前仍有明确行动；
- 关键事实已由适用的一手官方来源支持；
- 总分不低于 75。

标记后优先于普通常青题。多个时效题并存时，优先：

1. 剩余行动窗口更短；
2. 出错后更难补救；
3. 影响人数更多。

不得用时效优先放行证据不全或已经失效的题。

## 8. 排名与去重

无时效优先题时选择总分最高者。并列时依次比较：

1. 避免损失；
2. 即时有用性；
3. 覆盖人数；
4. 可执行性。

如可访问近 30 天发布记录，先做语义去重。相同结论、相同用户动作且无新增事实的内容视为重复，不因更换标题重新发布。

若所有候选题均低于 65 分或未通过硬门槛，返回 `NO_HIGH_VALUE_TOPIC`，不为保持更新频率生产低价值内容。分数只用于候选题比较，不证明成品有真实用户价值；最终状态仍由用户任务测试和价值证据决定。
